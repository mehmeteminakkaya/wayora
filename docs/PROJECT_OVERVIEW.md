# Wayora: Travel Planning (Proje Özeti)

> GrepThink'teki metin değişirse burayı da güncelleyin.

## Problem

Seyahat planlamak zaman alıcı ve yorucu. Gezginler ilgi alanlarına uyan yerleri bulmakta,
rotalarını düzenlemekte, bütçelerini yönetmekte ve gidilecek yerleri keşfetmekte zorlanıyor.

**Wayora**, kullanıcının tercihlerini, bütçesini, seyahat süresini ve ilgi alanlarını dikkate alarak
kişiselleştirilmiş öneriler ve yapay zekâ ile otomatik gezi planı (itinerary) üreten bir seyahat
planlama platformu. Hedef: seyahat planlamayı daha akıllı, kolay ve erişilebilir yapmak.

## Hedefler

1. Kullanıcı tercihlerine göre kişisel öneri üreten bir **AI seyahat asistanı**.
2. Bütçe, süre, ilgi alanı ve destinasyona göre **akıllı gün gün gezi planı**.
3. Gezilecek yer, restoran ve ilgi noktaları için **konum tabanlı servis** entegrasyonu.
4. Planları oluşturmak, yönetmek ve özelleştirmek için **kullanıcı dostu platform**.
5. AI ile planlamaya harcanan zaman ve emeği **azaltmak**.
6. Modern web teknolojileriyle **ölçeklenebilir, bakımı kolay** bir uygulama.

## Kapsam

- Responsive, modern bir web arayüzü
- Backend servisleri ve RESTful API
- AI ile kişisel öneri ve gezi planı üretimi
- Harita, konum ve destinasyon bilgisi için harici API entegrasyonu
- Kullanıcı profili, tercihler ve gezi planları için veritabanı
- Planı oluşturma / düzenleme / yönetme gibi etkileşimli özellikler
- Test, hata ayıklama, performans iyileştirme
- Git + GitHub ile ekip çalışması

## Teknoloji

React.js · TypeScript · Node.js · Express.js · PostgreSQL · REST API · Google Maps API ·
AI/LLM API · Git · GitHub
